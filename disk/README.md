# Poné aquí la imagen de tu CD de Space Clash

Copiá en esta carpeta la imagen del CD original de **Space Clash: The Last Frontier**:

- el archivo **`.bin`** junto con su **`.cue`**, **o bien**
- un archivo **`.iso`**.

El nombre de los archivos no importa. Los instaladores la encuentran solos.

Esta carpeta está excluida de git (`.gitignore`): la imagen del juego tiene copyright y no debe subirse
al repositorio.
